### FILTERS AND SORTING

Users should be able to filter applications by the information most useful for managing them.

Include:

* Search by application name
* Filter by status
* Filter by application type
* Filter by creation date
* Filter by last updated date
* Sort by newest
* Sort by oldest
* Sort by recently updated
* Sort by name

Status filters should include:

* All
* Draft
* Published
* Closed

Date filtering should support useful options such as:

* Today
* Last 7 days
* Last 30 days
* This year
* Custom date range

Use a clean filter bar or filter button that opens a compact filter panel. Make the active filters visible and easy to clear.

Include a result count, for example:

**12 applications**

Provide a **Clear filters** action whenever filters are active.
